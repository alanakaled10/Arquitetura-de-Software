# Aula 03 — Arquitetura de Software

## Monolito

### Conceito / Definição

É um modelo no qual todas as funcionalidades estão localizadas em uma única base de código e são implantadas juntas como um bloco único.

### Casos de uso comuns

- Sistemas de gerenciamento. Ex.: estoque, vendas etc.

### Principais vantagens

- Implantação simples

### Principais desvantagens

- Manutenção pode ficar complexa

---

## Distribuído

### Conceito / Definição

É uma arquitetura na qual o sistema é composto por vários computadores, servidores ou serviços independentes que trabalham em conjunto para realizar uma tarefa.

### Casos de uso comuns

- Sistema bancário e financeiro

### Principais vantagens

- Alta disponibilidade: se um componente falhar, outros podem continuar funcionando

### Principais desvantagens

- Maior complexidade e consistência de dados
